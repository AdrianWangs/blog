# Redis 知识库

![Redis 知识库](https://avatars.githubusercontent.com/u/1529926?s=200&v=4)

Redis 是一个开源的、基于内存的数据结构存储系统，可以用作数据库、缓存和消息中间件。本站收集整理了 Redis 相关的核心知识、最佳实践和常见问题解决方案。
