# LeetCode 41 - 缺失的第一个正数（First Missing Positive）

## 题目描述

给你一个未排序的整数数组 `nums`，请你找出其中没有出现的最小的正整数。

请你实现时间复杂度为 O(n) 并且只使用常数级别额外空间的解决方案。

## 解题思路

这道题的关键在于理解以下事实：如果长度为 n 的数组包含所有 1 到 n 的数字，那么缺失的第一个正数就是 n+1。如果存在缺失，那么答案一定在 1 到 n+1 之间。

我们可以利用数组本身作为哈希表，将值 x 放到索引 x-1 的位置，这样当我们再次遍历数组时，第一个不满足 nums[i] == i+1 的位置就是缺失的第一个正数。

算法分为两个阶段：

### 第一阶段：原地哈希排序

- 遍历数组，对于每个元素 nums[i]
- 如果 nums[i] 在 [1, n] 范围内，并且 nums[i] 不等于 nums[nums[i]-1]，则将其交换到正确的位置，即 nums[i] 应该放在索引 nums[i]-1 处
- 交换后，继续检查当前位置的新元素，直到无法再交换为止

### 第二阶段：寻找缺失值

- 再次遍历排序后的数组
- 第一个不满足 nums[i] == i+1 的位置 i，答案就是 i+1
- 如果所有位置都满足条件，则答案为 n+1

## 复杂度分析

- 时间复杂度：O(n)
  - 第一个循环中，虽然有嵌套循环，但每个元素最多被交换 O(1) 次，因为一旦一个元素到达正确位置，它就不会再移动
  - 第二个循环是 O(n) 的线性扫描
- 空间复杂度：O(1)，只使用了常数级别的额外空间

## 实现代码

```go
func firstMissingPositive(nums []int) int {
    n := len(nums)

    // 第一阶段：将每个数放到正确的位置
    for i := 0; i < n; i++ {
        // nums[i] 应该放在索引 nums[i]-1 的位置
        // 只处理在 [1,n] 范围内的值，且目标位置没有正确的值
        for nums[i] > 0 && nums[i] <= n && nums[nums[i]-1] != nums[i] {
            // 交换 nums[i] 和 nums[nums[i]-1]
            nums[i], nums[nums[i]-1] = nums[nums[i]-1], nums[i]
        }
    }

    // 第二阶段：找出第一个不满足 nums[i] == i+1 的位置
    for i := 0; i < n; i++ {
        if nums[i] != i+1 {
            return i + 1
        }
    }

    // 如果数组包含了 1 到 n 的所有数，则缺失的第一个正数是 n+1
    return n + 1
}
```

## 示例分析

以数组 `[3, 4, -1, 1]` 为例：

1. 第一阶段：

   - i=0: nums[0]=3，将其交换到索引 2，得到 `[-1, 4, 3, 1]`
   - i=0: nums[0]=-1，不在范围内，跳过
   - i=1: nums[1]=4，将其交换到索引 3，得到 `[-1, 1, 3, 4]`
   - i=1: nums[1]=1，将其交换到索引 0，得到 `[1, -1, 3, 4]`
   - i=1: nums[1]=-1，不在范围内，跳过
   - i=2: nums[2]=3，已在正确位置，跳过
   - i=3: nums[3]=4，已在正确位置，跳过

2. 第二阶段：
   - nums[0]=1，正确
   - nums[1]=-1，不等于 2，返回 2

所以缺失的第一个正数是 2。

## 易错点

1. 在第一阶段结束前就判断缺失值会导致错误，因为数组可能还没有完全排好序。
2. 内层循环的交换条件需要包含 `nums[nums[i]-1] != nums[i]`，否则可能陷入死循环。
3. 交换元素后，需要重新检查当前位置的新元素，因此使用的是 while 循环而不是 if 语句。
