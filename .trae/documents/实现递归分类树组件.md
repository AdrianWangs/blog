## 重构目标

创建一个全新的递归分类树组件，支持：
1. **无限层级递归展示** - 支持任意深度的分类嵌套
2. **可折叠/展开** - 每个有子分类的节点都可以点击展开/收起
3. **全宽展示按钮** - 点击后分类树占页面 90% 宽度
4. **风格统一** - 与 Butterfly 主题风格保持一致

---

## 实现方案

### 1. 创建自定义 Hexo Helper
**文件**: `scripts/helpers/category-tree.js`

- 递归构建分类树数据结构
- 生成支持无限层级的 HTML 结构
- 每个有子分类的节点都有展开/收起箭头

### 2. 创建分类树模板
**文件**: `source/_data/widget/category-tree.pug` (覆盖默认模板)

或通过 inject 方式注入自定义组件

### 3. 创建样式文件
**文件**: `source/css/category-tree.css`

```
设计要点：
- 树形缩进：每层缩进 16px
- 展开箭头：使用 Font Awesome 图标，点击旋转动画
- 悬停效果：淡蓝色背景
- 文章数量：右侧显示，灰色小字
- 层级连接线：可选的虚线连接
- 全宽模式：居中弹出，90% 宽度，半透明遮罩
```

### 4. 创建交互脚本
**文件**: `source/js/category-tree.js`

- 点击箭头展开/收起子分类
- 记住展开状态（localStorage）
- 全宽展示切换功能
- 平滑动画过渡

### 5. 更新配置
**文件**: `_config.butterfly.yml`

- 在 inject 中引入新的 CSS 和 JS
- 禁用原生分类卡片或替换
